# 008. 루트 랜딩페이지 화물맨 리브랜딩 + 히어로 배너 재디자인

## Context

**현재 상태**
- 운영 사이트 https://www.8080-8080.com 은 코드상 `src/app/(customer)/page.tsx` 루트 페이지에 대응한다.
- 기존 페이지는 "만차로" 브랜드 + 긴 스크롤 마케팅 구조 + Google Play 다운로드 CTA로 구성되어 있었다.

**왜 바꾸는가**
- 사용자가 제공한 마케팅 시안(배너형 레이아웃, "화물맨" 브랜드)에 맞춰 홈페이지를 갱신.
- 의사결정 사항:
  1. **전체 사이트 리브랜딩**: "만차로" → "화물맨" (컴포넌트/파일명까지 완전 교체)
  2. **히어로만 배너 디자인으로 교체**, 하단 섹션은 유지하되 텍스트만 리브랜드
  3. **메인 CTA는 Google Play + QR 유지**, `/landing` 위저드로의 직접 링크는 추가하지 않음
  4. **"학생이사"는 마케팅 문구로만 표시** (`MoveType` 스키마 수정 없음)
  5. **트럭 일러스트는 신규 SVG 컴포넌트로 생성**

## 변경 대상 파일

### 리네임 (파일 + 컴포넌트명)
- `src/components/brand/ManchaloLogo.tsx` → `src/components/brand/HwamulmanLogo.tsx`
  - `ManchaloLogo` → `HwamulmanLogo`, `ManchaloIcon` → `HwamulmanIcon`
  - 표시 텍스트 "만차로" → "화물맨", "용달이사 전문" → "이사 서비스"
- `src/components/brand/ManchaloFooterBanner.tsx` → `src/components/brand/HwamulmanFooterBanner.tsx`
  - `ManchaloFooterBanner` → `HwamulmanFooterBanner`
  - 표시 텍스트 "만차로" → "화물맨"

### Import 경로/이름 업데이트
- `src/app/(customer)/page.tsx`
- `src/app/(customer)/landing/page.tsx`
- `src/app/(customer)/estimate/page.tsx`
- `src/components/landing/LandingWizard.tsx`
- `src/components/estimate/HybridLayout.tsx`

### 신규 생성
- `src/components/brand/HeroTruckIllustration.tsx` — 인라인 SVG 트럭 + 박스/도시 배경 일러스트

### 본문 수정
- `src/app/(customer)/page.tsx` 히어로 섹션 배너형으로 전면 재구성 + 하단 카피 리브랜딩

## 구현 단계

### Step 1. 브랜드 리네임 (만차로 → 화물맨)
1. `HwamulmanLogo.tsx`, `HwamulmanFooterBanner.tsx` 신규 생성 (기존 SVG 디자인 유지 + 텍스트만 교체).
2. 사용처 5개 파일에서 import 경로/식별자 일괄 교체.
3. 본문 노출 카피: "왜 만차로인가요?" → "왜 화물맨인가요?", "만차로 앱을 다운로드하세요" → "화물맨 앱을 다운로드하세요" 등.
4. 기존 `Manchalo*.tsx` 파일 삭제.

### Step 2. 히어로 트럭 일러스트 컴포넌트 신규 생성
- `HeroTruckIllustration.tsx`: 인라인 SVG로 1톤 박스 트럭 + 박스 3개 + 도시 배경 + 구름.
- props: `{ className?: string }`.

### Step 3. 히어로 배너 재디자인
새 구성:
- 좌측 50% (모바일에서는 상단)
  - 카테고리 태그 pill (용달이사·일반이사·**학생이사**·원룸이사, 학생이사 강조)
  - 메인 타이틀: "화물맨 이사" / "**직접입력** 서비스"
  - 서브카피: "맞춤 차량과 이사 견적" 강조
  - 5단계 비주얼 (디스플레이 only, 클릭 불가)
- 우측 50% (모바일에서는 하단)
  - 노란 회전 배지: "간편하게 입력하고 빠른 견적 받자!"
  - `<HeroTruckIllustration />`
  - 체크리스트: 간편한 직접입력 / 맞춤 차량 매칭 / 빠른 견적 확인
  - 친절한 상담 박스 (🎧)
- 배너 아래 기존 Google Play + QR 유지

### Step 4. 하단 섹션 카피만 리브랜딩
- "왜 화물맨인가요?", "화물맨 앱을 다운로드하세요" 등 텍스트만 교체.
- 푸터 사업자정보(중기콜) 그대로 유지, 로고는 `HwamulmanLogo`로 교체.

## 명시적 비범위 (Out of scope)

- `/landing` 위저드, `/estimate`, `/mypage` 본문 변경 없음
- Play Store URL(`com.manchalo.app`) 유지
- DB, Supabase 함수, 환경변수 변경 없음
