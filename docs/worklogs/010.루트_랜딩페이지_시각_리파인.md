## 가공 방식

PowerShell + .NET `System.Drawing.Bitmap.Clone(Rectangle, PixelFormat)` 사용.

처음에 280px 간격으로 시도했지만 4·5번 아이콘이 어긋났음. 원본 이미지를 직접 확인 후 균등 분포 간격을 269px로 재계산하여 2차 크롭에서 정상 배치 완료. ARGB(32bpp) PixelFormat을 보존하여 알파 채널 유지.

## 시각 마무리 (Round 2.5)

사용자 피드백 반영하여 시안과 시각적 일치도를 더 끌어올림:

### 트럭 이미지 누끼
- 원본 `hmm_logo.png`(Format24bppRgb)에 회색 격자가 인쇄되어 있어 페이지에서 체스판 무늬가 노출됨.
- PowerShell + .NET `System.Drawing` + `LockBits`로 C# 코드를 컴파일해 픽셀 단위 처리:
  - R≈G≈B인 회색 톤(`|R-G| ≤ 8 && |G-B| ≤ 8 && |R-B| ≤ 8`)이고 값이 210~245 범위면 `alpha=0`으로 투명화.
  - 트럭 본체의 흰색(R=G=B≈255)은 보존, 그림자(R=G=B≈150~199)도 보존.
- 결과: 격자 무늬 완전 제거, 트럭+이사짐만 깔끔하게 남음.
- 출력 파일: `public/landing/hero-truck.png` (32bpp ARGB, ~2.1MB).

### 시안 참고 색상/폰트 조정 ([src/app/(customer)/page.tsx](src/app/(customer)/page.tsx))
- **카테고리 pill 배경**: `bg-slate-900` → `bg-primary` (네이비 통일).
- **학생이사 강조 색**: `text-primary`(진한 네이비, 시인성 떨어짐) → `text-yellow-300 font-bold` (시안과 동일한 노란 강조).
- **메인 타이틀 "직접입력"**: `text-primary`(너무 진한 네이비) → `text-blue-500` (시안의 밝은 파랑, 시인성 향상).
- **노란 회전 배지 → 둥근 네이비 말풍선 배지**: 시안 디자인에 맞춰
  - 배경: `bg-yellow-300 border-yellow-500` → `bg-primary`
  - 상단 텍스트: `text-gray-800` → `text-white`
  - 강조 텍스트("빠른 견적 받자!"): `text-blue-900` → `text-yellow-300 underline decoration-yellow-300`
