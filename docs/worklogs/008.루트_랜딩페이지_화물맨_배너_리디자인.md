# 008. 루트 랜딩페이지 화물맨 리브랜딩 + 히어로 배너 재디자인 (작업 완료)

작업일: 2026-05-11
작업자: Claude (Opus 4.7)

## 작업 요약

운영 사이트(https://www.8080-8080.com)의 루트 홈페이지를 화물맨 브랜드로 리브랜딩하고, 사용자가 제공한 마케팅 시안에 맞춰 히어로를 배너형 디자인으로 재구성했다.

## 변경 사항

### 신규 파일 (3개)
- `src/components/brand/HwamulmanLogo.tsx` — 화물맨 로고 (`HwamulmanLogo`, `HwamulmanIcon` 익스포트). 기존 만차로 로고의 SVG 디자인 유지, 텍스트만 "만차로/용달이사 전문" → "화물맨/이사 서비스" 변경.
- `src/components/brand/HwamulmanFooterBanner.tsx` — 푸터 배너 (`HwamulmanFooterBanner`). 텍스트 "만차로" → "화물맨".
- `src/components/brand/HeroTruckIllustration.tsx` — 히어로용 인라인 SVG 트럭 일러스트. 1톤 박스 트럭 + 박스 3개(노란 톤) + 도시 빌딩 배경 + 구름 + 차량 속도선 효과로 구성. primary 컬러(`oklch(0.702 0.209 41)`) 사용.

  - `grid md:grid-cols-2` 반응형: 모바일은 세로 스택, 데스크탑은 좌우 분할

## 검증

1. **타입 체크**: `npx tsc --noEmit` → ExitCode 0 (통과).
2. **잔존 참조 검증**: `src/**/*.{ts,tsx}` 전체에서 `Manchalo|만차로` grep → "No matches found".
3. **개발 서버 시각 확인**: `npm run dev` 실행 후 Playwright로 http://localhost:3000 캡쳐 → 배너 디자인이 시안과 흡사하게 렌더링됨을 확인 (트럭 일러스트, 노란 배지, 5단계 비주얼, 체크리스트, 친절한 상담 박스, Google Play CTA, 하단 섹션 전부 정상).

## 알려진 사항 / 후속 고려

- `qrcode.react`의 `includeMargin` prop이 v4에서 deprecated로 표시되지만 본 작업과 무관(기존 코드에 이미 있던 경고). 추후 별도 작업으로 마이그레이션 필요.
- 트럭 일러스트는 인라인 SVG로 자체 구성했으며, 추후 실제 일러스트 자산이 준비되면 `<HeroTruckIllustration />` 호출부를 `<Image src="/hero-truck.png" />`로 교체하면 됨.
- 외부 앱 ID(`com.manchalo.app`) 변경 여부는 별도 작업으로 결정 필요.
